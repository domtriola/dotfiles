# Manual Setup Steps

Steps that no script in this repo does.

## Caps Lock remap (macOS)

Open System Settings, go to Keyboard > Keyboard Shortcuts > Modifier Keys, and
set the Caps Lock key to Control. Repeat it for every attached keyboard, since
the setting is per keyboard.
